# Frontend

React frontend foundation built with Vite.

## Commands

- Install: `npm install`
- Start locally: `npm run dev`
- Build: `npm run build`
- Preview the production build: `npm run preview`

## Routes

- `/` — Ticket List
- `/tickets/new` — Create Ticket
- `/tickets/:ticketId` — Ticket Detail

API integration is intentionally deferred to IMP-020.
