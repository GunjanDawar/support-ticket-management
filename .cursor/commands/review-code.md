# Review Code

Review the current implementation against:

1. Relevant specifications under /spec.
2. Applicable Cursor rules.
3. Architecture.
4. API contract.
5. Business rules.
6. Validation requirements.
7. Error handling.
8. Security requirements.
9. Test coverage.
10. Maintainability.

Do NOT modify any files.

Report findings under:

## Critical
Issues that can cause incorrect behaviour, security problems, data corruption,
or violation of core requirements.

## Major
Issues that significantly affect maintainability, correctness, architecture,
or testing.

## Minor
Smaller improvements.

For every finding provide:

- File
- Problem
- Why it is a problem
- Relevant specification/rule
- Recommended fix

Clearly distinguish confirmed defects from optional suggestions.

Do not invent issues.
